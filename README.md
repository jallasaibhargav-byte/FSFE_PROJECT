PROJECT TITLE: Hotel Website Content Management System (CMS) & Interactive Booking Widget
----*ABSTRACT*----

1. INTRODUCTION
In the modern hospitality industry, a seamless digital presence and an intuitive reservation process are essential for maximizing direct bookings and enhancing guest satisfaction. This project focuses on the design and development of a responsive, user-friendly Hotel Website featuring an integrated Content Management System (CMS) and a dynamic Booking Widget, built entirely using core web technologies: HTML5, CSS3, and Vanilla JavaScript.

2. PROBLEM STATEMENT
Many independent hotels and boutique resorts rely heavily on third-party Online Travel Agencies (OTAs) due to the high cost and technical complexity of maintaining custom websites with real-time booking capabilities. Furthermore, updating room availability, seasonal pricing, and promotional content often requires developer intervention, leading to delays and operational inefficiencies.

3. OBJECTIVES
- To design a visually appealing, responsive hotel showcase website that adapts seamlessly across desktop, tablet, and mobile devices.
- To develop an interactive Booking Widget that allows guests to filter available rooms, select check-in/check-out dates, specify guest counts, and calculate total stay costs dynamically.
- To build a lightweight, client-side Content Management System (CMS) interface enabling hotel administrators to easily add, edit, or remove room listings, update pricing, and manage special offers without writing code.
- To utilize browser-based storage mechanisms (such as LocalStorage) to persist CMS updates and simulate real-time synchronization between the admin dashboard and the guest-facing booking portal.

4. METHODOLOGY & TECHNOLOGIES USED
- HTML5: Used to structure the semantic layout of the hotel showcase, room galleries, booking forms, and the administrative CMS dashboard.
- CSS3: Employed for modern styling, utilizing Flexbox and CSS Grid for responsive layouts, custom variables for consistent theming, and smooth transitions to enhance user experience.
- JavaScript (ES6+): Powers the core application logic, including DOM manipulation, form validation, dynamic price calculation based on date ranges, interactive room filtering, and CRUD (Create, Read, Update, Delete) operations within the CMS module.

5. EXPECTED OUTCOMES
The resulting web application provides a dual-interface solution: an engaging, friction-free booking experience for prospective guests and an empowering, easy-to-use management portal for hotel staff. By eliminating reliance on heavy frameworks or complex backend setups for prototyping, this project demonstrates how foundational web technologies can effectively solve real-world hospitality management challenges.
